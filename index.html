Driftbound Labs

Independent applied research. Emphasis on method.

Method

Work is pre-registered where possible. Decision rules and null tests are fixed before data is examined. Artifacts are hashed so results can be checked against what was actually run. Negative outcomes are reported as negative outcomes.

The scientific method is treated as operational practice, not branding.

Current work

Physical-layer integrity for synchronized time: using shared geophysical signals as a cross-site reference to bound clock offset in ways cryptographic authentication does not. Early validation used published multi-station data under pre-declared criteria. Further measurement under controlled sensor and site conditions is required.

Direction

The longer path is a data pipeline that supports frontier work in the physical sciences.

The intent is to use structured data and machine learning to help identify research questions that are both open and tractable — problems where the necessary measurements, constraints, and decision criteria can be stated clearly enough that the work can actually be completed. The same standards apply: pre-registration, hashed artifacts, and explicit limits.

Timing integrity is one instance of that approach, not the definition of the lab.
